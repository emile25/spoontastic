# Spoontastic

A small browser prototype about reading the bend of a spoon.

## Run locally

Requirements: Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

## Controls

- Swipe left or right across the spoon.
- Use the Left and Right buttons, or the arrow keys / A and D.
- Buy Silver Clarity with earned money to increase future rewards.

Progress is saved in this browser with `localStorage`.

## Checks

```sh
npm test
npm run build
```
