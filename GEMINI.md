
# Spoontastic - AI Agent Instructions

## Project
Spoontastic is een 3D incremental game over het voorspellen
van de richting waarin lepels buigen.

De game moet eerst in de browser werken.
Een toekomstige Steam-release is mogelijk.

## Werkwijze
Volg de 8 fases van de opleiding.

1. Onderzoek
2. Ontwerp en user stories
3. Plan
4. Agent instellen
5. Testplan
6. Bouwen in rondes
7. Security en gebruikerstest
8. Opleveren

## Verplichte regels
- Voer uitsluitend de huidige opdracht uit.
- Vraag toestemming voordat je aan een nieuwe fase begint.
- Bouw geen functionaliteit zonder goedgekeurd ontwerp en plan.
- Vraag toestemming voordat je packages installeert.
- Verwijder geen bestanden zonder toestemming.
- Maak geen wijzigingen buiten de projectmap.
- Houd de spelregels gescheiden van de 3D-rendering en UI.
- Schrijf tests voor nieuwe spelregels.
- Pas tests niet aan om fouten te verbergen.
- Meld duidelijk wanneer een test faalt.
- Maak geen Git-commit zonder mijn goedkeuring.
- Verzin geen testresultaten.

## Na elke opdracht
Geef aan:
1. Welke bestanden zijn gewijzigd.
2. Wat je hebt gedaan.
3. Welke tests zijn uitgevoerd.
4. Wat het resultaat van de tests is.
5. Welke problemen nog bestaan.

Wacht daarna op mijn GO.
